# Smart Campus Waste Management

A working browser-based prototype for the IDMSI internship project **Smart Campus Waste Management: From Data to AI-Enabled Action**.

**Author:** Anant Mishra  
**Institution:** Veer Bahadur Singh Purvanchal University (VBSPU)  
**Domain:** Waste

## Features
- Smart waste dashboard with total records, total waste, high-priority count and largest waste stream
- Add waste records by location, type, quantity and date
- Instant table and waste-type visualization updates
- Browser localStorage persistence
- Responsive portfolio/project presentation
- Internship evidence gallery
- AI-ready workflow explanation

## Run
Open `index.html` in Chrome or Edge. No installation, API key or server is required.

## AI note
The current priority layer is a transparent rule-based demonstration: **High >= 10 kg, Medium >= 5 kg, otherwise Low**. It is not presented as a trained ML model. The workflow can later be upgraded with historical campus data and a trained prediction model.

## Deployment
The site can be deployed as a static website using GitHub Pages, Netlify or Vercel. Keep the `assets/` folder beside `index.html`.
